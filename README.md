# Minecraft Skylines

Walk around your Cities: Skylines city as a Minecraft player. Cities: Skylines stays the game on
screen and keeps simulating the city; Minecraft Java runs hidden next to it and supplies the
player: movement physics, inventory, hotbar, crafting, placing and breaking blocks, and (the
ambitious part) digging into the city's own terrain.

Inspired by [SkyCraft](https://github.com/chasmlol/SkyCraft) (the same idea for Skyrim).

**Status: milestone 1 (the bridge) in progress. Nothing runs in the games yet.** See
`docs/MILESTONES.md`.
